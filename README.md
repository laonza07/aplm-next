# APLM Next

เว็บแยกจาก `D:\dev\aplm2027` ตามภาพแนวคิดน้ำเงิน–ขาว–ทอง พร้อมตรามหาวิทยาลัยและตราสำนักต้นฉบับ เมนู OASS และปุ่มสมัครเรียน

## เปิดใช้งาน

ต้องมี Node.js 20 ขึ้นไป ไม่ต้อง `npm install`

```powershell
cd D:\dev\aplm-next
npm run dev
```

เปิด http://127.0.0.1:4177 หรือดับเบิลคลิก `Start-APLM.cmd` แล้วเปิด URL นี้
เปลี่ยนพอร์ตได้ด้วย `$env:PORT=4180` ก่อนรัน ไม่เปิดรับการเชื่อมต่อจากนอกเครื่อง

## ความสามารถ

- เมนูหลักแบบ Mega Menu เปิดด้วยคลิก/คีย์บอร์ด ปิดด้วย Escape หรือคลิกด้านนอก และเมนูมือถือ
- รวมลิงก์ OASS ต้นฉบับครบ 191 จุด พร้อมค้นหา กรองหมวด ล้างคำค้น และแสดงเพิ่มเติม
- ปุ่มสมัครเรียนเปิด https://app.sskru.ac.th/admission/register และบริการนักศึกษาเปิดระบบเดิม
- ภาพประกอบสามมิติ, parallax ตามการเลื่อน, reading progress และรองรับ reduced motion
- Responsive, focus states, skip link, status ประกาศผลค้นหา, ฟอนต์และรูปเก็บในโปรเจกต์
- ปุ่มโหมดมืด / สว่างบนหัวเว็บ จำการเลือกในเครื่อง หากยังไม่เคยเลือกจะใช้โหมดตามระบบ และยังสลับได้เมื่อเบราว์เซอร์ปิดกั้น localStorage
- ข่าวอ้างอิงรายการจริงจาก OASS ระบุวันที่ snapshot ไม่ใช่ feed สด

## แก้ไขข้อมูล

- `index.html`: เนื้อหาหลักและปุ่ม CTA
- `styles.css`: สี ขนาด responsive และการแสดงผล
- `app.js`: พฤติกรรมเมนู ค้นหา และ scroll
- `data/oass-links.json`: ข้อมูลดิบจาก OASS เก็บ ID/URL เดิมไว้
- `scripts/catalog.mjs`: ตั้งหมวด ชื่อเมนู ข่าว และหมายเหตุ แล้วรัน `npm run build` เพื่อสร้าง `data/catalog.js` ใหม่
- `assets/`: ตราจริง ภาพประกอบ และฟอนต์
- `reference/approved-homepage.png`: ภาพต้นแบบก่อนเริ่มพัฒนา เมนูจะปิดตอนโหลดเว็บและเปิดเมื่อกด ต่างจากภาพต้นแบบที่แสดงตอนเปิดเมนู

## ตรวจสอบและนำไปใช้งานบนโฮสต์

```powershell
npm run check
npm run build
```

นำเนื้อหาใน `dist/` ขึ้น static hosting ได้ ไม่ต้องใช้เซิร์ฟเวอร์ Node ใน production รองรับโฮสต์ใน subfolder เพราะใช้ relative asset paths

## ขอบเขตข้อมูล

ระบบสมัครเรียน/ทะเบียนเป็นระบบภายนอกเดิม ไม่ได้สร้างฐานข้อมูลหรือระบบจัดการข่าวใหม่ ตรวจเปิดหน้าสมัครเรียนได้เมื่อ 15 ตุลาคม 2569 แต่ยังไม่ได้ล็อกอินหรือส่งใบสมัคร
ลิงก์ OASS อื่นอาจเป็นข้อมูลย้อนหลัง ต้องใช้สิทธิ์ หรือเปลี่ยนปลายทาง รายการที่ไม่มีชื่อจากรูปต้นฉบับแสดงชื่อไฟล์ ไม่สมมติชื่อบริการ ส่วน URL ที่รายงานต้นฉบับพบความคลาดเคลื่อนจะแสดงหมายเหตุ เว็บไซต์นี้เก็บปลายทางเดิมครบถ้วนเพื่อให้ตรวจทานต่อได้

ภาพเส้นทางการเรียนรู้สร้างด้วย ImageGen เป็นภาพแนวคิด ไม่ใช่ภาพสถานที่จริงของมหาวิทยาลัย ตราทั้งสองคัดลอกจากไฟล์ที่ผู้ใช้ให้มาโดยไม่วาดใหม่ ยังไม่ได้เผยแพร่ขึ้นโดเมนจริง

## ผลการตรวจสอบ

ผ่านการทดสอบด้วย Chromium แบบ headless: เมนูเดสก์ท็อป/มือถือ, Escape, ค้นหา/ล้างคำค้น/ไม่พบข้อมูล, กรองหมวด, แสดงเพิ่มเติม, โหลดรูปและฟอนต์, reduced motion และหน้าจอ 360, 390, 600, 768, 900, 1024, 1440 พิกเซล ไม่พบ horizontal overflow หรือ JavaScript/HTTP error ระหว่างทดสอบ
ภาพตรวจงานเก็บใน `.qa/` (ไม่รวมใน `dist/`) สคริปต์ `scripts/browser-check.mjs` เป็นเครื่องมือตรวจเฉพาะการพัฒนา ต้องมี playwright-core ใน `.qa/tools/package` ก่อนรัน ไม่ใช่ dependency ของเว็บ
